Roll back
The Case When Rollback Is Useful:
• Attacker V0 sends bad data ( send Fake position ).
• Honest neighbor V2 uses that bad data in its own estimator ( trust detected late , V1 also).
• Later host vehicle V1 receives V2 fleet estimate of V0 .
• From V1 perspective, V2 is honest, but V2  estimate is already contaminated upstream.
• Even later V1 see V2 is malicious , V1 already contaminated , so the pure prediction will go wrong
